# 可运行版本

本开发分支根目录 `OUTSIDE.html` 使用生活内容 0.6.0，包含 A 线四次相遇、三天转发栏入口及原 19 篇阅读内容。ABCD 全部接完前不合并；B/C/D 尚未实现。旧 0.3/0.4/0.5 局按原版本继续，体验 A 线需新局。认知规则仍为 0.4.0；下列命名归档保留各自发布时的内容。读取新帖后的存档需要当前或更新的 HTML。

- [余下的三天 / 0.5.0](OUTSIDE-three-days-0.5.0.html)：未知结构后自动接续 12 个日常事件，短工、维护、消息修订、再次赴约和迟到的留言。沿用 0.4 认知规则；已有 0.3/0.4 局保持原流程，开始新局进入三天。
- [摘要与记忆目录版 / 0.4.0](OUTSIDE-context-memory-0.4.0.html)：容量 100，真正归组合并、目录计费、scope 漂移、仅回想摘要、不可展开的旧记忆合并与遗忘。0.3.0 局继续按原规则运行；新局使用新版。
- [持续上下文与阅读版 / 0.3.0](OUTSIDE-life-reading-0.3.0.html)：主线与午后共享 1000 容量、按来源整理，包含长文转发栏、大字和书签。
- [独立午后版 / 内容 0.2.1](OUTSIDE-2026-09-14-cognition-0.2.1.html)：此次改动前实际存在的完整 HTML，含原四结局和可随时进入的独立午后。可用于对照或导入过去的午后 JSON。
- [主线整合版 / 内容 0.2.2](OUTSIDE-journey-content-0.2.2.html)：Fable 之后、正式入口之前的可选停留，共用旅程资源与备份。
- `builds/OUTSIDE-before-时间.html`：每次构建覆盖根目录文件前，自动保留发生变化的上一份 HTML。是仅保留在本地、不上传 Git 的构建过程快照，未逐份独立验收；试玩优先选上面有名称的版本。

这些是完整离线 HTML，不需要配套 assets 文件夹。Git 历史从本次公开仓库整理开始；更早、已经被覆盖且未留下文件的发行版本无法补回。

不同文件路径的浏览器存储可能不同。换版本前先导出 JSON，并在对应版本导入。0.3.0 接受原 v1 主线与已完成章节的旧旅程；旧进行中的午后用 0.2.2 整合版恢复，独立午后 JSON 用独立版恢复。自动载入不兼容时，新版提供“导出保留的原存档”，不会覆盖它。
