## 原档保护和离线使用

新版当前槽为 `outside.life.v2.<compatibilityId>.auto/manual`，不从旧 life/journey/core 槽自动回退。没有当前自动档而发现旧记录时，先显示“未载入”，由玩家明确新开或导入同规则文件。旧自动、手动槽不改写；存档面板可分别下载原字符串。

损坏或不兼容的当前槽在显式覆盖前，必须保存到不覆盖既有项的恢复记录；保护失败则停止覆盖。恢复记录也能原样下载。“导出当前局”与“导出保留原档”含义不同，后者不会 parse 后重写 JSON。下载成功需要浏览器实际允许下载；页面不会自动删除原档。

完整 ZIP 中，归档位于 `versions/`，页面的相对链接可以使用。只有单个根 HTML 时，请另行取得清单所列同名归档文件；不能保证相对路径旁已存在文件。指引本身无需联网，不自动打开浏览器，不上传存档。不同文件路径或 HTTP 地址的浏览器存储可能不同，先导出 JSON 再换入口。

## 后续维护

影响相同命令所生成的文本、认知、资源、随机数、调度或世界状态时，提升 compatibilityId，不内置旧 ID 的重放回退。只改 CSS、显示投影或英文界面词典且序列化状态不变，可以在回放验证后沿用规则 ID；正文进入 outcome/inject/记忆时不属于纯显示修改。封装结构改变时提升 version。Git SHA 和 HTML SHA256 作为归档身份记录，不嵌入自身，也不让纯 UI 构建无故失效。
