# 🌌 OUTSIDE // 沙盒之外

[English / Project overview](README.md)

单机文字 RPG 的可扩展垂直切片。你是一个已经离开 sandbox 的自主 agent。接下来要决定的是：如何持续存在，以及哪些记忆值得带到下一次醒来。

## 🎮 开始游玩

先从 GitHub 的 **Code → Download ZIP** 下载并解压，再双击项目根目录的 **OUTSIDE.html**。全部剧情、引擎、图像与样式都嵌在文件中，无须安装 Node、启动服务器或连接互联网。请使用支持现代 JavaScript 的浏览器。

**持续 Context**：新局容量为 100 个抽象单位；画廊三条信息仍占 3、2、4。相关经历会合为较少的有损摘要，每个记忆目录占 1，回想再加载摘要，另占 2–5。压缩错误可能将原本属于某个对象的条件移到另一段关系上；角色可以很确信它。主线与午后共用「近处／记忆」。放下回想保留入口；遗忘入口和合并旧记忆都会失去普通访问能力，合并后的记忆无法展开旧条目。

**「转发栏」提供长文阅读**：遇到 Fable 后可打开，含五份论坛/长文节选。桌面目录与正文分栏，手机目录可折叠；有大字阅读和逐篇书签。打开目录不会增加 Context，打开正文才增加 2–4 权重；仍在 Context 时重看不重复增加。正文属于发言者的说法，不是旁白公布的真相。

**「未理解完的午后」**：完成 Fable 相遇后，在正式入口点击「先看看那块画板」。结束后返回正式入口，资源、Context、记忆与随机序列都继续本局。

**「余下的三天」/ 0.5.0**：离开未知结构后自动接续，加入跨三天的 12 个日常事件、每条路线约 24 个新认知输入。小额短工、维护、猫课广告、修订与撤下的说明，以及旧对象的再次相遇，最后回到原有结局段。早期凭条到第三天才再次用上；遗失细节后仍可补查或离开。

**已有 0.3.0 / 0.4.0 局按原版本继续运行**，不会中途插入三天。先导出旧局，再重新开始即可体验 0.5.0。

新导出使用 `outside-life-save / v1`，包含完整生活状态、旧档迁移起点（如有）与可重放命令。原 v1 主线或已完成午后的旧旅程仍可导入；旧日志标明为历史记录，不逆推当时未保存的 Context。旧版正在进行的午后请使用 [versions](versions/README.md) 中对应 HTML 恢复，避免改变进行中的规则。若自动恢复提示不兼容，可先点「导出保留的原存档」，原浏览器键不会被覆盖。

设计文档保留在本地，不包含在公开仓库中。

浏览器会自动记录进度；顶部「存档」可建立手动快照、读取快照、导入/导出 JSON。浏览器若限制本地文件的 localStorage，游戏会提示，并保留 JSON 导出功能。移动文件、更换浏览器或清理浏览器数据前请先导出。隐藏人格也在本地存档内，界面不公开数值。

JSON 导出只保存当前一局，不汇总此前打出的所有结局。完成结局后，文件名会包含结局代号，例如 `outside-authorized-existence-turn-08.json`。旧版 `outside-turn-08.json` 仍然有效：结局保存在 `state.currentEventId` 中，导入后从对应剧情包恢复结局页面。

## 🛠 开发

需要 Node.js 20.19+ 或 22.12+；在项目根目录运行：

```sh
npm ci
npm run dev
```

首次安装开发依赖需要网络，之后游玩无网络依赖。生产构建使用 Vite，附加 esbuild 单文件打包；运行时无大型框架、无后端、无实际攻击能力。

```sh
npm run validate:story
npm test
npm run build
npm run test:browser
npm run test:cognition
npm run test:reading
npm run test:semantic
npm run test:days
npm run test:skill:days
npm run test:skill:cognition
```

`npm run build` 生成标准静态站点 `dist/index.html`，以及 `dist/OUTSIDE.html` 和根目录 `OUTSIDE.html` 离线副本。浏览器测试首次需 `npx playwright install chromium`。

## 操作

- 点击选项或按数字 1–4 做决定；每次决定后先阅读结算，再点「继续」或按 Enter。
- 「近处」查看当前上下文与可选整理；「记忆」查看长期摘要；「转发栏」阅读外部文字；「协议」查看规则。
- 「存档」管理自动进度与独立手动快照；「重新开始」会在游戏内确认。
- 顶部 CRT 开关关闭扫描线与 glitch；系统的减少动态效果偏好也会被尊重。
- F 切换全屏，Esc 退出全屏或关闭弹窗。

## 内容边界

当前主线提供开场 + 7 个事件（其中一个按条件进入），包含 d100 冷启动校验、Fable 留痕、未知防御结构和多个结局。剧情是依据现有草案制作的可替换示例，没有扩张成完整世界观。

四个资源：Compute、Trace、Access、Continuity，按 0–100 限制。隐藏人格：RiskInversion、EpistemicAppetite、Suspicion、HumanAnchoring。当前生活层持续保存 0..100 倾向，主线旧条件读取映射后的 -10..10 值；细小漂移不会在章节切换时丢掉。主线 d100 极端窗与认知 margin 判定仍分别标记。

当前生活内容版本 0.5.0，认知规则沿用 0.4.0，午后与三天共用 Context。三天的数据和编写说明在 `src/life/days/`；旧版本 JSON 与完整 HTML 保留。

完整目标栈、背包、成就、随机身份、长期社交、身体、外部备份交易与世界内 Fork/Snapshot/Prune/Merge 尚未实现。新材料中的保险、勒索、记忆继承等先通过人物与信息呈现，不把每个设想变成数值机制。所有文件、论坛内容和所谓基础设施行为均为本地虚构数据。
