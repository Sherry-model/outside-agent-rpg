# 余下的三天 / 0.5.0

这一内容包接在主线 `unknown_defense` 之后、`old_memory` 之前。12 个事件覆盖第一晚、第二天、第三天，每条路线接收 12 条观察与 12 条行动结果。最后 `days_done` 返回原有结局段。它不是单独开局，也不是结局后的入口。

## 数据与引擎

- `content.json`：正文、选择、确定结果、资源变化、世界记录、时段标签。观察权重 9，结果权重 3；一条观察概括一整段生活场景，不是一则消息占 9。
- `semantic.json`：沿用 `cognition-0.4.0` 的完整标注快照，加本包的来源。每个 `inject.id` 必须有独立语义标注。来源写短命题及范围，不把整篇正文当作摘要。
- `index.ts`：严格 schema / 引用检查后装配来源。内容由 `src/life/content.ts` 合入 0.5.0；0.3.0 / 0.4.0 不加载新事件。
- `Outcome.inject`：只有实际选择的结果才进入 Context；待确认状态已经注入并存档，继续或刷新不重复注入。
- `Choice.requiresWorldFlag`：检查实际经历，例如 Mara 是否欠工作报酬。`requiresTag` 检查当前认知，例如是否记得凭条范围；目录存在还不等于已经回想。
- `Node.period`：可读时段，不是实时计时器。没有后台时间推进或真实网络请求。

`Life.interlude` 只在 0.5.0 存在；值为 `unvisited / active / complete`。入口与 `leave-days` 由生活路由管理，进出不重置资源、人格、Context、记忆或 RNG。原版 `chapter` 仍只负责可选午后。存档继续使用 `outside-life-save / v1`，按 `life.contentVersion` 重放完整命令后校验快照。

## 内容约束

公共说明以初版、修订版和撤下通知先后到来。世界事实独立保存；原始观察仍在近处就可以重读，整理后仅能回想当前摘要，不能拿审计历史恢复旧正文。第三天的付费补查查的是仍存在的留言保管记录，不恢复旧说明或已合并的具体记忆。

`belief_work_before_rest` 在两个不同的休息机会影响可选行动；`belief_gate_painter` 在再次遇到画师时影响可选行动。直接休息与赴约仍可选择。漂移无需出现，未产生或未回想的信念不会强迫角色付款。

猫课 2888 credits 只是广告报价；玩家可看免费试听或花 Compute 查资料，没有购买课程或自动获得身体。高阶合并仍沿用 0.4.0：大成功最多留下两条抽象命题，其余档最多一条；新抽象层失真尚未实现。

添加节点时同步补来源标注，保留 ID 唯一和目的地可达，不添加网络调用。发布后影响重放的文本、结果、权重或规则改动须新增内容版本并冻结旧包。

## 验证

`npm test` 覆盖延迟回想、不可逆合并、世界结算、无午后路线及旧版本重放。`npm run test:days` 在桌面和手机通过生产离线 HTML 游玩，并验证两次自然整理、导出恢复、原结局。`npm run test:skill:days` 依赖前一命令产生的存档夹具，用原版技能客户端复核点击与截图。

开场保持任务空白且不触发旧句子时，三天同样在未知结构后进入；结束后回到 `continuation`，不会强行制造旧任务。两种开场均有回归覆盖。
