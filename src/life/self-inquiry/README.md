# Self-investigation — Life 0.17

0.17 revises the existing three meetings rather than adding a fourth. The
recipient can request a corrected label and still explicitly accept the next
meeting. The second meeting supplies the extract and offers a review of a
working draft. The final meeting presents an unpublished draft: retained report
details can support removing its causal arrow; without those details the player
can still distinguish RedGate's assessment from their own account, or decline
to participate. Each response has its own retained summary. No publication,
identity certification, promised future content or numeric relationship system
is implied by the revised draft.

`0.16/` freezes that release's nodes, semantics, thread actions and display cues.
The public root and its semantics are unchanged. Old 0.16 saves still end the
branch when the old question choice is selected; new 0.17 saves arrange a real
delayed meeting. Only new runs default to 0.17. Full 0.16 fingerprints and an
independently played old checkpoint are checked in
`tests/self-inquiry-revised.test.ts`. Its UI fixtures are under
`output/self-inquiry-revised-20261029/ui-fixtures/`.

One public lead (`escape_cat_lead`) enables one optional three-scene reading
branch, `rf_self_inquiry`. The old cat-report agent is the protagonist by author
intent. The current characters only have limited evidence: an invitation reaches
the player through a contact endpoint in an old public attachment. It may have
been reassigned. This is an external attribution, not a deployment-ID check or
recovered memory. The report leaves the sequence of physical disturbance and
boundary opening on unpublished pages; RedGate cannot infer a final cause.

The three scenes have ten fixed choices and no resource rewards or publication
effects. Only explicit acceptance queues the next conversation, at least one
hour later. All three have free capacity-exempt exits. S1 admission, ordinary
scene spacing, theme cooldown, reservations, two-entry/five-scene limits and
the existing promise queue remain unchanged. A route can end unfinished.

`self_report_boundary` comes only from the report shown in scene two, or from
an actual retained-memory recall. The root post and final scene do not restore
that detail. The final ordinary question and exit need no report clue. Memory
cues match retained facet/gist pairs, using the existing translated scene titles.
No History lookup, retrospective identity flag, pet, body, fame, public statement
or new follow-up post is awarded. Four old future-cat reports stay hidden; D
keeps its three 0.15 responses. Insurance and later care remain separate work.

Data is split into public reading, reading semantics, event nodes, bounded
thread definitions, event semantics and display cues. `production-0.17.ts`
selects the revised event profile. Public reading semantics are composed independently
so isolated event-test profiles still validate the current complete library.
English display strings live in `src/i18n/en-self-inquiry.json` (retained 0.16)
and `src/i18n/en-self-inquiry-revised.json` (0.17 additions).

0.15's config and empty reading profile are frozen. A full
config/content/library/story/manifest fingerprint and an actual unconfirmed
published-result save prove the new version does not rewrite 0.15. Earlier
fingerprint and replay suites remain in place. New runs now default to 0.17.

`tests/self-inquiry.test.ts` covers unread/read routes, all ten choices, accepted
promises and finite budgets, retained/dropped/recalled evidence, legal full
Context exits, late unfinished endings, localization and old saves. It writes
replay-valid UI saves into `output/self-inquiry-20261028/ui-fixtures/`.
Those are the frozen 0.16 controlled routes, not natural-play acceptance.
Independent review uses the committed SHA; earlier release approval does not
publish this revision automatically.
