# Painter life / Life 0.18

Two optional scenes continue the existing painter acquaintance. This is a partial implementation of the painter Thread and automatic News, not closure of ADD-010/OPT-011.

- Familiarity requires actual `daily_painter_connected` and `daily_opinion_seen`. Reading a meme cannot qualify. At hour 24+, a safe optional invitation can be accepted or declined. Accepting adds an ordinary scheduler commitment; it does not start a forced encounter. Respond via Life. Existing queue order/overdraft apply, with authored entry-capacity checks.
- `painter_sync`: distinguish the old sunset thumbnail from the new **Night Platform** image. Help costs 2 Compute; watching does not claim help. Both may arrange a return 72 hours later. Leaving stops invitations. Helping changes the current preview mode on return.
- `painter_revisit`: concrete accurate-detail / recalled sunset-belief / ordinary conversation / exit responses. No knowledge reconstructed from History. A finite authored scope-migration rule can mix the actual old thumbnail and new work only on the existing compression failure/fumble; no new RNG or forced result. The optional `DriftRule.belief` supplies the mistaken proposition; old rules retain their prior conditional wording.
- Public News at hours 24/96 is independent of participation. `life/news.ts` consumes a single eligible message only after a real safe transition/wait, with a 2-point capacity check and ordinary-scene/time separation. It uses the same cognition `receiveNews` injection as authored `Node.receive`. The delivery ledger holds IDs/timing only. UI bodies come from current Context, and the arrival banner is limited to its delivery command.
- New fields/commands are strict-replayed. 0.17 config/content/schedule/reading/story fingerprints and a genuine pre-change save are regression-tested. Old behavior is unchanged.

Developer checks: `npm test`, `npm run build`. New regression tests include real-command acquaintance, 72-hour return, refusal/nonparticipation, capacity and duplicate delivery, real seeded drift with recall, bilingual data, frozen graph and old save. Browser and natural-play acceptance are separate, delegated to Astra.

## OPT-029 / rules r2

Actual helpers receive 4 Compute on entering the 72-hour return, once, clamped to 100; the earlier 2 Compute cost remains. A present external receipt records the actual credited amount, without restoring forgotten detail. Watching, declining the invitation, or leaving without a return does not earn a payment. A return reserves 4 Context (the scene and, for helpers, its receipt).

Three non-exit replies lead to one short depiction offer; direct farewell still returns immediately. Both helpers and watchers can choose a private version, public endpoint attribution (Trace +2, clamped), or a free capacity-exempt refusal. Acquaintance-specific wording follows actual world facts, while new observations and distinct summaries remain subject to forgetting. New arrival material is shown before any automatic compression; ordinary manual management stays available.
